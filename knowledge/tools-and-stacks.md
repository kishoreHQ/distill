# Recurring tools and stacks

Drawn from `knowledge/tools.yaml` and the source ledger. A name here means a cited post discusses it.

## Agent harnesses and coding CLIs

- **Claude Code.** Levels credits it with finding vendor-cost cuts [pieter-levels S3] and describes a year of coding with it on a VPS [pieter-levels S5]. Tw93 lists the CLI among a smaller set of daily apps [tw93 S10].
- **Codex.** Steinberger writes about many Codex review instances [peter-steinberger S7]. Dörr's own observation is that Claude is good at driving Codex [tom-dorr S7].
- **OpenClaw and Hermes.** The OpenClaw README is in Steinberger's ledger [peter-steinberger S3]. Saboo says his group started on OpenClaw and later also used Hermes, both from Telegram [shubham-saboo S7].
- **MCP.** Mishra comments on an official EKS MCP server from AWS [akhilesh-mishra S10]. Other MCP servers appear inside aggregator feeds. Those feeds are not seated as experts. See `profiles/gittrend` and `profiles/x-githubprojects`.

## Hosts, schedulers, and glue

- **Cron plus an LLM API.** Levels' solo-stack essay [pieter-levels S4].
- **Hetzner.** He posts shipping from a phone onto a Hetzner VPS [pieter-levels S13].
- **GitHub Actions.** Dörr's repo feed is rebuilt on a schedule [tom-dorr S16].
- **Kestra, Terraform, Ansible, ServiceNow.** Mishra's orchestration essay walks through that chain. The ledger says it is unclear whether the post was sponsored [akhilesh-mishra S4].
- **Stripe and self-serve billing.** Named in the same Levels essay as the cron workers [pieter-levels S4]. No integration guide is stored beyond that description.

## Stacks people argue against

- **Kubernetes as a default.** Gupta's quote says he runs from that orchestration vocabulary [arnav-gupta B-2]. Mishra still teaches Kubernetes and says DevOps is not the logo list [akhilesh-mishra S5]. Both are in the corpus. See the careers board.
- **Microservices as a default.** Piyush says he flipped and now thinks most companies do not have the problem microservices solve [piyush-sachdeva S13]. Gupta's line is harsher [arnav-gupta O-ENG-4].
- **Postgres as the stated default.** "99% of info-system software should be just Postgres (and Redis)." [arnav-gupta O-ENG-1].

## Not a buying list

Julian Goldie, Nav Toor, and the aggregator accounts name many tools in a promotional or feed format. Those mentions are not copied into this list unless a first-party source above also discusses the tool. Sponsored-post status is often unknown because the bundles say the paid-partnership field was not requested.
